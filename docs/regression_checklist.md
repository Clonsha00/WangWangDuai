# UI 回歸測試清單 (Regression Checklist)

此清單用於人工驗證 DMS 系統的核心操作介面是否運作正常。在重構或調整底層邏輯後，請依序執行以下測試項目：

## 1. 導航與全局路由
- [ ] 執行 `python main.py` 後，首頁 (Home Dashboard) 是否正常開啟。
- [ ] 點擊左側 Sidebar 的選單，是否能順暢切換 Home / Finance / Action / Knowledge 四個頁面。

## 2. 財務模組 (Finance)
- [ ] 財務頁上方表單能否成功新增「收入」與「支出」。
- [ ] 點選不同分類標籤 (Chips) 後，是否能正確寫入資料庫並在下方列表顯示。
- [ ] 財務金額輸入中文字或無效符號時，是否會顯示紅色 SnackBar 警告且**不閃退**。

## 3. 行動中樞 (Action)
- [ ] 能否正常新增日常任務 (Daily TODO)。
- [ ] 點擊未完成任務的 Checkbox 後，是否能標記為完成並從主要列表中隱藏/移到底部。
- [ ] 左上方的習慣打卡 (Habits) 是否能正常點擊 Toggle 並即時記錄狀態。

## 4. 知識庫 (Zettelkasten)
- [ ] 能否在右側編輯器成功新增卡片，並即時反映在左側列表中。
- [ ] 能否透過 Dropdown 選單選擇其他卡片，並成功建立「正向關聯」。
- [ ] 點選刪除卡片前，是否會正確顯示確認對話框 (AlertDialog)。
- [ ] 確認對話框中，是否會詳細列出受影響的「正向關聯」與「反向連結」。
- [ ] 點擊確認刪除後，透過 DB 工具或 `tests/test_db.py` 確認 `relations` 表無殘留該卡片的孤立連結。

## 5. 系統層與資料持久化
- [ ] 新增/修改任意模組資料後，關閉並重新啟動程式，資料是否依然保留。
- [ ] 進入專案根目錄，檢查 `backups/` 資料夾是否正常產生當日的 `dms_backup_YYYYMMDD.db` 備份檔。
